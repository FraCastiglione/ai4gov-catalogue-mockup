# AI4Gov-X Extracurricular Activities Catalogue Mockup

Static visual prototype for an improved AI4Gov-X extracurricular activities catalogue page.

## Files

- `index.html` - the single-page catalogue mockup
- `ai4gov-logo.png` - AI4Gov-X logo asset
- `ai4gov-hero.png` - hero background image used by the mockup

## Viewing Locally

Open `index.html` in a browser.

## Publishing With GitHub Pages

After pushing this repository to GitHub:

1. Open the repository settings.
2. Go to **Pages**.
3. Set source to **Deploy from a branch**.
4. Choose branch `main` and folder `/root`.
5. Save.

GitHub will provide a public URL for the mockup.
